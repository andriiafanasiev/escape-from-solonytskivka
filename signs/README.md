# Вивіски

Поклади сюди свої картинки з точно такими назвами файлів (PNG, JPG або WEBP).
Гра підхопить їх сама, у всіх, хто відкриє сайт. Картинку можна будь-якого розміру — гра вписує її у вивіску і доповнює краї кольором картинки.
Якщо хтось вибере свою картинку в Налаштування → Вивіски, у нього вона буде замість файлу з цієї папки.
